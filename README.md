# RecipeBox - Recipe Manager App

A fully functional recipe manager that allows users to save recipes, search by ingredient, and mark favorites. A working recipe app with recipe saving, ingredient search, and favorites.

## Features

- Save recipes with title, ingredients, and steps
- Search recipes by ingredient
- Mark recipes as favorites

## Modules

- `recipebox_recipe_manager_app`: save_recipes_with_title_ingredients_and_steps, search_recipes_by_ingredient, mark_recipes_as_favorites

## Tech Stack

React, Tailwind CSS, localStorage
